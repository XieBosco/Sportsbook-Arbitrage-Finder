60: copy 60 bytes from old

61: this is NOT a copy but a "jump old cursor to position 61"
5: copy 5 bytes from old[61:66]

80: jump old cursor to position 80
11: copy 11 bytes from old[80:91]
So the pattern is: copy, insert, [jump, copy, insert]*, jump, copy where after each insert, the next int is a JUMP (absolute position in old), then a copy count, then another insert.
